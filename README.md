# MaixCAM Pro 轻量拼图视觉程序

本目录只包含一个设备入口 `main.py`。程序只实现“识别黑色 A4 -> 透视校正 -> 检测纸内白色碎片 -> 多边形化 -> 边匹配虚拟拼图 -> 评分显示”，没有 UART、STM32、抓取点、模板、扑克牌纹理、放置复检或复杂 UI。

## 运行

1. 在 MaixVision 中打开整个 `D:\26_new` 文件夹。
2. 连接 MaixCAM Pro 后运行根目录 `main.py`。程序使用 `640x480 RGB888`，启动时仅调用一次 `skip_frames(30)`。
3. 让完整黑色 A4 纸进入画面。启动后程序只识别一次 A4，并缓存四点和透视矩阵。
4. 顶部左侧 `FIND A4`：相机或 A4 移动后，手动重新识别并更新缓存。
5. 顶部右侧 `SOLVE ONCE`：只对当前帧执行一次透视、碎片检测和拼图求解。结果页保持缓存；普通循环不重复运行这些算法。
6. MaixVision 的停止按钮或设备功能键可退出。

没有 MaixPy 的 PC 可以运行无摄像头合成自检：

```powershell
python main.py --self-test
```

该命令生成一张带透视黑色 A4 和 3 块白色碎片的合成图，只验证 OpenCV 流程，不访问摄像头。

## 算法

- A4：RGB 只读视图 -> 灰度 -> GaussianBlur -> Otsu 反二值 -> 闭运算 -> 外轮廓 -> 四边形、凸性、面积与 A4 长宽比筛选；通过 `getPerspectiveTransform` 缓存矩阵，校正为 `420x594`，比例为 `2 px/mm`。
- 碎片：只处理透视后的 A4 图。灰度固定阈值二值化，只做一次 3x3 闭运算以避免开运算削圆尖角，清除 5 px 纸边并提取外轮廓。对全部 3～5 点 `approxPolyDP` 候选计算轮廓 IoU 和面积误差，选择质量最高者；再对每条原始轮廓边使用 `fitLine`，用相邻拟合直线交点细化顶点，最多保留 4 块。
- 拼图：算法流程以 [`lvreng/puzzle-vision-simulator`](https://github.com/lvreng/puzzle-vision-simulator/tree/160dcad0c0a7163021893aa1018579b926715222) 的全局拓扑方法为基础。先统一多边形绕序，建立排序后的相近边候选表，再枚举 `N-1` 条接缝的树形拓扑和 `N` 条接缝的单闭环拓扑，不再强制每块度数为 2。若一条长边近似等于另外两块或三块的短边之和，会在求解内部插入 1～2 个虚拟共线分点，支持“一长边对两短边”和“一长边对三短边”。完整边和各虚拟分边方案按每批 64 个拓扑轮询，不再把一个错误分边穷举完才尝试下一个。沿拓扑传播 SE(2) 位姿后，先用连续几何的尺寸和总面积必要条件快速排除不可能结果，只有较好的候选才创建像素掩膜；排名靠前的闭环候选再执行 pose-graph 优化。
- 严格解与逆合成：优先返回通过填充率、重叠、尺寸、并集四边形及直角检查的严格矩形。若严格解不存在，则从搜索中保留的候选里做“最小逆合成”，只旋转和平移原碎片，不拉伸或修改轮廓，并按最终矩形内的缺口、重叠和尺寸误差选择代价最小的布局。宽松解仍须满足官方尺寸范围、填充率至少 `0.78`、重叠率最多 `0.08`；界面明确显示黄色 `INVERSE FIT`，不会伪装成严格 `OK`。
- 显示：原图 A4 四边形、校正图碎片轮廓及顶点、彩色虚拟组合及最终矩形，同时显示 FPS、候选数、尺寸、填充率、空隙/重叠面积和步骤耗时。搜索期间左下角约每 250 ms 刷新真实进度条，并显示百分比、已检查拓扑数和“已用时间/最大时间”，可据此区分正常检索与卡死。`c600/r3` 表示检查了 600 个拓扑，但只有 3 个进入了昂贵的栅格评分。没有严格解或宽松解时才显示最佳无效候选的 `FILL/OVERLAP/SIZE/RECT` 失败项及数值；触及候选数或时间上限时显示 `SEARCH LIMIT`。

参考仓库的固定提交中未提供可读取的 `LICENSE` 文件，因此本项目只按其公开描述和算法结构独立适配，没有复制 GUI、场景生成器、固定 10x6 cm 目标布局或大段源码。

## 主要参数

都集中在 `main.py` 顶部：

- `WHITE_THRESHOLD = 165`：白碎片灰度阈值，现场最优先调整。
- `A4_MIN_AREA_RATIO = 0.18`：A4 至少占画面 18%。
- `A4_RATIO_TOLERANCE = 0.35`：透视前轮廓长宽比容差（允许明显透视缩短）。
- `EDGE_LENGTH_TOLERANCE = 0.15`：全边匹配及“长边≈两短边之和”的相对误差不超过 15%。
- `MAX_EDGE_MATCH_CANDIDATES = 40`：全局边长候选表最多保留 40 项。
- `MAX_SOLVE_MS = 6000`：单次拼图搜索最多运行 6 秒；配合实时进度条，给虚拟分边回退足够时间，同时避免异常输入长期占住设备循环。
- `SEARCH_PROGRESS_INTERVAL_MS = 250`：检索进度画面最短刷新间隔。
- `TOPOLOGY_BATCH_SIZE = 64`：每个完整边或虚拟分边方案每轮最多连续检查 64 个拓扑，防止正确分边被排在数千个错误候选之后。
- `POSE_GRAPH_ITERATIONS = 20`：胜出拓扑的全局闭环优化迭代上限。
- `MAX_SPLIT_VARIANTS = 10`：一长边对两短边的虚拟分边回退最多尝试 10 种组合。
- `MAX_THREE_WAY_SPLIT_VARIANTS = 18`：一长边对三短边的虚拟分边回退最多尝试 18 种组合。
- `MAX_REFINED_TOPOLOGIES = 40`：最多对软评分靠前的 40 个闭环拓扑做数值优化。
- `MIN_FILL_RATE = 0.85`、`MAX_FINAL_OVERLAP_RATIO = 0.05`：现场宽松档的最终填充率和重叠率门槛，用于容纳轮廓拟合及透视误差。
- `INVERSE_MIN_FILL_RATE = 0.78`、`INVERSE_MAX_OVERLAP_RATIO = 0.08`：只有严格解不存在时使用的最小逆合成门槛。
- `MAX_INVERSE_FIT_CANDIDATES = 60`：最多对 60 个快速预筛候选补做栅格评分，控制兜底耗时。
- `MIN_LONG_MM/MAX_LONG_MM = 90/120`、`MIN_SHORT_MM/MAX_SHORT_MM = 50/90`：最终尺寸硬门槛。
- `RECT_ANGLE_TOLERANCE_DEG = 20`：并集外轮廓必须近似四边形，且四角相对 90° 的最大允许误差。
- `PIECE_MIN_AREA_RATIO` / `PIECE_MAX_AREA_RATIO`：相对 A4 面积的碎片筛选范围。
- `MAX_COMPLETE_CANDIDATES = 6000`：异常等长边场景的单次求解安全上限；屏幕候选数带 `+` 表示触及上限。
- `QUICK_GEOMETRY_MARGIN = 0.03`：连续几何预筛保留 3% 栅格化余量，避免因像素取整误删临界解。

## 耗时说明

结果页显示本次设备实际测得的 `warp`、`binary_morph`、`contours`、`approx_poly`、`solve` 和 `total` 毫秒数，预览页显示当前 FPS。这里没有启动或占用摄像头，因此不能把 PC 合成自检时间写成 MaixCAM Pro 真机性能；真机数据应以屏幕和 MaixVision 终端上的一次触发结果为准。

当前 Windows PC 合成端到端快速路径实测约 4 ms，其中求解约 2 ms，最佳尺寸 95.0x59.9 mm、填充率约 0.992。前三张实拍截图都已加入严格解顶点回放：第一张约 126 ms、检查 841 个拓扑，得到 111.5x76.4 mm、填充率 0.957；第二张约 38 ms、检查 204 个拓扑，得到 116.6x77.5 mm、填充率 0.886；第三张的正确解原本排在第 12767 个拓扑，分批轮询后约 97 ms、在第 618 个拓扑找到 118.7x78.3 mm、填充率 0.868、重叠率 0.0340、最大直角误差 12.88° 的合格解。第四张不规整碎片截图也已加入回放：严格条件下无解，逆合成在 Windows PC 上约 1.5 秒检查 5306 个拓扑，得到约 98.2x54.8 mm、填充率 0.814、重叠率 0.049 的 `INVERSE FIT`。自检还覆盖 2 块直线切割、4 块中心放射切割、T 形切割、进度回调和非法尺寸拒绝。上述数值只证明流程已实际运行，不能代表 CV181x 真机耗时。

现场建议先固定相机和 A4，再调曝光/照明及 `WHITE_THRESHOLD`。若移动相机或纸张，点 `FIND A4`；若缓存校正后的纸边不再以黑色为主，`SOLVE ONCE` 会判定缓存失效并要求重新识别。
