# MaixCAM Pro 保存布局检测程序

本目录只包含一个设备入口 `main.py`。程序现在只保留“识别黑色 A4 -> 透视校正 -> 检测纸内白色碎片 -> 保存/删除/按保存模板检测显示”这条轻量流程，不再做自动拼图拓扑搜索。

## 运行

1. 在 MaixVision 中打开整个 `D:\26_new` 文件夹。
2. 连接 MaixCAM Pro 后运行根目录 `main.py`。程序使用 `640x480 RGB888`，启动时仅调用一次 `skip_frames(30)`。
3. 让完整黑色 A4 纸进入画面。没有独立 `FIND A4` 按键；程序会在预览和按键动作时自动识别/刷新 A4。
4. 顶部共有三个按键：
   - `SAVE`：把当前 A4 内已经拼好的矩形样子保存下来，包括每块碎片的轮廓、面积、边长签名和在矩形中的槽位顺序。
   - `DELETE`：手动删除已保存模板。
   - `CHECK`：检测当前 A4 内的碎片，与保存模板做形状匹配，并在左下角按之前保存的矩形位置显示重排结果。
5. 保存文件为同目录 `saved_layout.json`。设备掉电后不会丢失；只有按 `DELETE` 或手动删除该文件才会清空。
6. MaixVision 的停止按钮或设备功能键可退出。

没有 MaixPy 的 PC 可以运行无摄像头合成自检：

```powershell
python main.py --self-test
```

该命令生成一组带透视黑色 A4 和 3 块白色碎片的合成图，验证保存、加载、匹配、删除和结果页绘制流程。PC 端需要可导入 `cv2` 的 Python 环境。

## 算法

- A4：RGB 只读视图 -> 灰度 -> GaussianBlur -> Otsu 反二值 -> 闭运算 -> 外轮廓 -> 四边形、凸性、面积与 A4 长宽比筛选；通过 `getPerspectiveTransform` 缓存矩阵，校正为 `420x594`，比例为 `2 px/mm`。
- 碎片：只处理透视后的 A4 图。灰度固定阈值二值化，只做一次 3x3 闭运算，清除 5 px 纸边并提取外轮廓。对多组 `approxPolyDP` 候选计算轮廓 IoU 和面积误差，选择质量最高者；再用相邻拟合直线交点细化顶点。
- 保存：按屏幕位置从上到下、从左到右记录碎片槽位，保存每块的多边形、面积、顶点数、质心和归一化边长签名。
- 检测：重新识别当前碎片后，按面积、边长比例和顶点数对保存模板做全排列匹配。数量不一致会显示 `COUNT 当前/保存`；形状差异过大会显示 `WEAK MATCH`。
- 显示：左侧显示原图和 A4 四点，右侧显示透视后的碎片轮廓，左下角显示保存下来的矩形模板或匹配后的重排预览，并显示 FPS、检测片数、面积和耗时。

## 主要参数

都集中在 `main.py` 顶部：

- `WHITE_THRESHOLD = 165`：白碎片灰度阈值，现场最优先调整。
- `A4_MIN_AREA_RATIO = 0.18`：A4 至少占画面 18%。
- `A4_RATIO_TOLERANCE = 0.35`：透视前轮廓长宽比容差（允许明显透视缩短）。
- `PIECE_MIN_AREA_RATIO` / `PIECE_MAX_AREA_RATIO`：相对 A4 面积的碎片筛选范围。
- `MAX_PIECES = 6`：最多记录/检测 6 块碎片。
- `MATCH_SCORE_LIMIT = 0.45`：保存模板和当前碎片的平均形状匹配分数上限，越小越严格。
- `A4_REFRESH_MS = 1000`：预览状态下自动尝试刷新 A4 的间隔。

## 现场建议

先把碎片手动拼成目标矩形并按 `SAVE`；之后可以把碎片打乱放回 A4 内，按 `CHECK` 查看是否能按保存模板识别并显示成原来的矩形。若光照变化导致检测片数不对，优先调整曝光、照明和 `WHITE_THRESHOLD`。
